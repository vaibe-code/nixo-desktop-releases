# Nixo Desktop · Downloads

Installer für **Nixo Desktop**, den Code-Agenten von [Nixo](https://nixo.codes).

Lade die passende Datei unter [Releases](https://github.com/vaibe-code/nixo-desktop-releases/releases/latest) herunter:

| System | Datei |
| --- | --- |
| Windows (x64) | `Nixo-Setup-<version>-x64.exe` |
| macOS (Apple Silicon) | `Nixo-<version>-mac-arm64.dmg` |
| macOS (Intel) | `Nixo-<version>-mac-x64.dmg` |
| Linux | `.AppImage` (aktualisiert sich selbst), `.deb`, `.rpm` |

Die App sucht beim Start und alle 6 Stunden nach Updates und installiert sie beim nächsten Neustart. Mit `.deb` und `.rpm` aktualisierst du über deinen Paketmanager.

Dieses Repo enthält nur die Installer. Der Quellcode ist nicht öffentlich.
